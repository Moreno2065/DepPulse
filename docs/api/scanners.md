# deppulse.scanners

Language-specific scanners implementing the `BaseScanner` interface.

::: deppulse.scanners
    options:
      show_root_heading: true
      show_source: false
```

## Available scanners

- `PythonScanner` — Python source files using `ast` module
- `JavaScanner` — Java source files using `javalang`
- `KotlinScanner` — Kotlin source files using tree-sitter
- `CppScanner` — C/C++ source files using tree-sitter
- `JavaScriptScanner` — JavaScript/JSX source files using tree-sitter
- `TypeScriptScanner` — TypeScript/TSX source files using tree-sitter
